---

An APS interpretation would be weakened if viability conditions were inferred only from the fact of persistence; if proposed constraints lacked an evidenced organisational role; if the comparison account had been understated; if a claimed dependency proved unnecessary; or if the analysis produced no explanatory result beyond existing biology.
